# 직접 정렬 처리 검증 결과

- Ubuntu용 GCC 13.3.0, C++17, -O2 -Wall -Wextra -Wpedantic으로 빌드.
- make test 전체 통과. 컴파일 경고 없음.
- 기존 190개 사례의 송신/변환 결과 총 380개 프레임이 수정 전과 완전히 동일.
- 같은 380개 프레임을 Python struct 기반 독립 계산과 비교하여 모두 일치.
- 정렬 137개, msgcode 58개, 매핑/인터페이스, 비트필드 14,052개 검사 통과.
- 추가 시험: 중첩 가변 버퍼/구조체 배열/1바이트 후속 필드, 고정 기대 바이트 및 크기,
  왕복 변환, 28개 잘린 패킷 거부/롤백, 수신 패딩 무시와 재송신 0 채움 통과.
- LayoutStep과 별도 배치 목록 제거. API와 JSON 스키마 유지.
- dump의 내부 구조체 끝 패딩 표시는 다음 필드 앞 패딩으로 합쳐 표시.
- CMake 실행 도구는 환경에 없어 Makefile 경로로 전체 빌드/시험 수행.
- 검증 로그: direct_alignment_make_test.log.
